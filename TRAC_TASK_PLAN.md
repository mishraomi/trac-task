# Trac Task React Prototype

## Summary

Build a React + TypeScript Vite web application that starts at Login and recreates every supplied desktop and mobile state as a responsive, browser-local prototype. Seed data matches the mockups and interactive data changes persist in the browser.

## Included experience

- Authentication: login, registration, forgot/reset password, and email invitation acceptance.
- Workspace: dashboard, shared list tasks, search/filtering, task completion, edit/delete/details, list sharing and member management.
- Profile preferences plus empty/no-results/error-style recoverable states.
- Original generated scenic artwork for auth screens and code-native UI controls/icons.

## Technical approach

- React, TypeScript, Vite, and Lucide icons.
- Typed in-memory domain data, with browser persistence as the next extension point.
- Responsive desktop and mobile layouts, with mockup states accessed through natural interaction.

## Verification

- Validate production build.
- Exercise login, list/task operations, invitation, modal flows, and narrow-screen layout.
